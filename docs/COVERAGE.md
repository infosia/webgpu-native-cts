## Status legend

| Status | Meaning |
|--------|---------|
| **ported** | All (or all in-scope) tests in the file are ported and run on at least one backend |
| **partial** | Some tests ported; others skipped/unimplemented (list which) |
| **N/A** | No native analog (e.g. WebIDL `TypeError` coercion tests, web-platform-only); not portable |
| **deferred** | In scope eventually but intentionally postponed (e.g. shader execution) |
| **todo** | Not started (default) |

A test marked `.unimplemented()` in a ported file counts the file as **partial**.

## Current state

`api/validation`, `shader/validation`, and `shader/execution` are complete (0 todo). `api/operation` has
every portable file opened (70/72; the two N/A files are the JS-`ArrayBuffer` map files
`buffers/{map_ArrayBuffer,map_detach}`), with several files still partial — they register their upstream
test names but leave native-portable breadth or web/JS-specific subcases `.unimplemented()`. The `compat`
area (15 files) and the root/example stubs remain todo. Conformance findings surfaced while porting are
tracked in [FINDINGS.md](FINDINGS.md), not here. yawgpu currently passes the whole ported suite (fail=0,
crash=0) on native Metal and native Vulkan, using the Tint WGSL frontend.

Notes on the pre-classified rows:

- **`web_platform` (13) → N/A**: canvas, `importExternalTexture` from `HTMLVideoElement`/`VideoFrame`,
  workers — these depend on the web platform and have no native C-API analog. See
  [00-overview](00-overview.md) non-goals.
- **`idl` (3) → N/A**: WebIDL surface/constant tests; the C API has no IDL layer.
- **`shader/validation` (207) and `shader/execution` (239) → both COMPLETE** (0 deferred). Shader execution
  covers all structural files + the entire `expression/call/builtin` family (atomics, texture,
  sync/derivative, integer/bit/pack, the math/trig builtins on a ported **FP-interval acceptance framework**
  — f32/f16/abstract — all binary/unary operators, conversions, constructors, access) + the
  `subgroup*`/`quadBroadcast`/`quadSwap` execution builtins (on a ported `subgroup_util` compute/fragment/
  accuracy engine) + `texture_utils` (a meta-test of the CTS texture random-data / texel-readback /
  sampling-weight helpers — not a plain util). Dawn advertises `WGPUFeatureName_Subgroups` on Metal and runs
  subgroup execution and validation there (subgroup-size gates honored; Dawn-Metal `subgroupMaxSize=32`).
  `shader/validation` covers `extension`/`shader_io`/`decl`/`functions`/`types`/`const_assert`/`uniformity`/
  `parse`/`statement`/`expression` including all 114 builtin signature/type/const-overflow validation specs,
  and is **byte-equivalent to the Dawn reference** (the earlier F-130 divergence no longer reproduces). See
  [07-roadmap](07-roadmap.md).
- **`api/regression`, `shader/regression`**: 0 files at this revision.

These classifications are provisional; revisit per file when the area is worked.
